Hebbian learning, "neurons that fire together wire together", changes each synapse using only what the two neurons it joins are doing. No global loss function is in sight. The note this page grew from asks how that can work, and what the network is then doing. This page studies one model in which the first question has an exact answer: a resistor network whose neurons have transfer functions. There, the local rule is gradient descent on a single global objective, the network's own energy averaged over its inputs plus a cost per synapse, and each synapse sees exactly its own component of the gradient. The second question is what the rest of the page measures, against four things the note hoped for. Two of them hold in an exact form, one as stated and one after a correction. Two largely fail in the basic model, and for each the page names what is missing.

The question

The note begins: "It's remarkable that this works because there is no global loss function. How then, or what, is the brain doing?" Its proposal is a resistor network. Neurons are nodes with voltages, synapses are conductances, and a set of input neurons is clamped to the activity of the rest of the brain. The Hebb rule, with a regulariser on each weight, should then sort the interior neurons into discrete clusters, each tied to an eigenmode of the input. The note made four further claims, and these are what I tested:

  • (T1) Diversity within a cluster. Each cluster is an expansion code: many neurons that see the same mode but compute different random functions of it, a reservoir for downstream use.
  • (T2) An allocation law. The homeostatic parameters act as a spectral filter that sets how many neurons a mode of variance $\lambda$ receives, $n(\lambda)$.
  • (T3) Clusters are eigenmodes. Each population becomes isomorphic to the eigenmode of the input it represents.
  • (T4) Weight-space readout. From the weights alone, solve for the covariance of the input.

The model

$B$ input neurons are clamped to a stimulus $g \in \mathbb R^B$, drawn from a distribution $p_g$ with zero mean and covariance $\Sigma_g$. $N$ interior neurons have voltages $u_i$. Interior neurons are joined to one another by plastic, symmetric conductances $w_{ij} = w_{ji} \ge 0$. Each is attached to a few inputs by fixed conductances $a_{ib} \ge 0$: on this page, $s$ randomly chosen inputs with shares that sum to one. Each neuron also has an on-site potential $V_i$, convex. The energy, counting each pair once, is

$$\begin{aligned}E_W(u; g) = {}& \tfrac12 \sum_{i<j} w_{ij}\,(u_i - u_j)^2 \\ &+ \tfrac12 \sum_{i,b} a_{ib}\,(u_i - g_b)^2 + \sum_i V_i(u_i).\end{aligned}$$

For a given stimulus the voltages relax quickly, $\tau\,\dot u_i = -\partial E_W/\partial u_i$, to the minimum of $E_W$. The minimum is unique because $E_W$ is strictly convex in $u$ once every neuron has an attachment. It satisfies the node equation

$$\begin{gathered}d_i\,u_i + V_i'(u_i) = I_i, \\ I_i = \sum_j w_{ij}\,u_j + \sum_b a_{ib}\,g_b, \\ d_i = \sum_j w_{ij} + \sum_b a_{ib}.\end{gathered}$$

Read it as a neuron. A current $I_i$ arrives through the synapses and the attachments, and the neuron answers with the voltage $u_i = (d_i\,\mathrm{id} + V_i')^{-1}(I_i)$. So the derivative of the on-site potential, added to the leak $d_i u$, is the inverse transfer function, and choosing a convex $V_i$ shapes the transfer function. Convexity bounds the gain: the slope of the transfer function is $1/(d_i + V_i''(u))$, never more than $1/d_i$, so the potential can make a neuron less responsive than the plain resistor node in some range of currents, never more. The default here is a two-slope quadratic with a threshold $t_i$ of the neuron's own,

$$V_i(u) = \tfrac{k_{lo}}{2}\,(u - t_i)_-^2 + \tfrac{k_{hi}}{2}\,(u - t_i)_+^2 .$$

With $k_{hi} = 0$ it is a leaky rectifier: below threshold the neuron's gain drops from $1/d_i$ to $1/(d_i + k_{lo})$. The potential is piecewise quadratic, so the equilibria are computed exactly, not to a tolerance.

The equilibrium voltage of neuron $i$, as a function of the stimulus, is its response function $F_i(g)$. It depends on the weights, $F_i = F_i^W$. Response functions are the objects this page is about: they are what the network computes, and they are what learning groups together.

The linear limit. With $V_i = 0$ the node equations are linear, and $u = Hg$ with $H = (\mathrm{diag}(d) - W)^{-1}A$, the discrete Poisson kernel of the graph. Each row $h_i$ of $H$ is non-negative and sums to one, since constant inputs give constant voltages. So $h_i$ is a probability distribution over the inputs, the note's harmonic embedding, and the response function is linear, $F_i(g) = h_i \cdot g$.

One result: a local rule that descends a global objective

Learning is slow compared with relaxation, so it only ever sees equilibria. Let it descend

$$\begin{aligned}J(W) = {}& \mathbb E_g\Big[\min_u E_W(u; g)\Big] \\ &+ \sum_{i<j}\Big(\frac{\alpha}{2}\,w_{ij}^2 - b\,w_{ij}\Big).\end{aligned}$$

The first term is the energy the network settles to, averaged over stimuli: the cost of reconciling the clamped inputs, the attachments, the synapses and the neurons' own potentials. The second is a cost per synapse, a decay $\alpha$ and a constant drive $b$.

The derivative of a minimum with respect to a parameter is the partial derivative at the minimiser. The minimiser moves too, but the gradient in $u$ vanishes there, so its motion contributes nothing to first order (the envelope theorem). $E_W$ depends on $w_{ij}$ only through $\tfrac12 w_{ij}(u_i - u_j)^2$, so $\partial_{w_{ij}} \min_u E_W(u; g) = \tfrac12\big(F_i(g) - F_j(g)\big)^2$. Gradient descent on $J$ is therefore

$$\begin{gathered}\frac{dw_{ij}}{dt} = b - \alpha\,w_{ij} - \tfrac12 D_{ij}^2, \\ D_{ij}^2 = \mathbb E_g\big[(F_i - F_j)^2\big] = \|F_i - F_j\|^2,\end{gathered}$$

projected so that $w_{ij}$ stays non-negative: an edge at zero whose drift is negative stays at zero.

Key point

The rule is local: a synapse needs only the average squared voltage difference across itself, which it can sense. Yet the network as a whole descends one objective, $J$. There is a loss function after all. No part of the network computes it, because it is the network's own equilibrium energy.

The Hebbian reading. Expanding the square,

$$-\tfrac12 D_{ij}^2 = \underbrace{\mathbb E[F_i F_j]}_{\text{coactivity}} - \tfrac12\,\mathbb E[F_i^2] - \tfrac12\,\mathbb E[F_j^2].$$

The first term is Hebb's: the two neurons' (uncentred) coactivity. The other two subtract each neuron's activity power. So a pair is drawn together by being alike, not by being loud. The note's rule kept only the first term, $\langle h_i, h_j\rangle_{\Sigma_g}$; the old-rule chapter shows what that does.

The fixed point. Setting (5) to zero, with the projection,

$$w_{ij}^\ast = \frac{\big(b - D_{ij}^2/2\big)_+}{\alpha}.$$

An edge lives exactly when $D_{ij}^2 < 2b$, and its weight is then a known linear function of the distance. Pruning is built in. $b$ sets the range of fusion, a length $\sqrt{2b}$ in the space of response functions, and $\alpha$ sets its strength: $b/\alpha$ is the largest conductance an edge can reach, to be compared with each neuron's total attachment conductance of 1. Note that (7) is not a formula for $W$, because $D_{ij}$ itself depends on $W$: each edge pulls its pair together and shrinks $D_{ij}$. The first term of $J$ is a minimum of functions linear in $W$, hence concave. So $J$ is not convex, fusion reinforces itself, and several fixed points can coexist. Which one the network reaches depends on its history (the fusion chapter works this out for two neurons and watches it in thirty).

The geometry is exact

The distance in (5) is the $L^2$ distance between response functions under the input distribution, with inner product $\langle F_i, F_j\rangle = \mathbb E_g[F_i F_j]$. Two neurons are close when they respond alike to the stimuli that actually occur; differences on stimuli that never occur cost nothing. In the simulations the expectation is the plain mean over a fixed training bank of stimuli, the bank learning uses. The identities above hold exactly for that bank. Claims about the population are checked on an independent evaluation bank.

For linear neurons, $F_i(g) = h_i \cdot g$, and

$$\begin{aligned}D_{ij}^2 &= (h_i - h_j)^\top C\,(h_i - h_j) \\ &= \sum_a \lambda_a\,\big((h_i - h_j)\cdot v_a\big)^2,\end{aligned}$$

where $C = \mathbb E[g g^\top]$ is the uncentred second moment of the inputs ($\Sigma_g$ for the population, $\hat C = G^\top G/S$ for a bank $G$ of $S$ stimuli), with eigenpairs $(\lambda_a, v_a)$. This is a covariance-weighted distance between harmonic embeddings: a difference along a loud input direction counts for more than the same difference along a quiet one. Every row of $H$ sums to one, so $(h_i - h_j)\cdot\mathbf 1 = 0$ and only contrasts between inputs count. Two consequences are developed later. For two neurons whose embeddings differ by $\delta$ along a single mode $a$, the edge between them grows from $W = 0$ exactly when $\delta < \sqrt{2b/\lambda_a}$, a resolution law (many inputs). And every live synapse records one linear equation on $C$ (readout). For nonlinear neurons the same geometry holds in function space. The rule then compares whole functions, not vectors of input weights, and that is what gives a cluster room to hold different functions.

What we found

First, the clusters themselves (fusion, many inputs). With random attachments, raising $b$ takes the network from singletons, through chains wider than one edge's range, to one blob. No range of $b$ holds a few clean clusters whose number the inputs set. At small $\alpha$ the components are tight, but their number keeps falling with $b$ and depends on the path taken. Clean clusters appear when the attachments already group the neurons, for instance when each neuron is wired to one block of inputs, and the chapters that use such wiring say so. Against the four targets:

What we found

  • fails(T1) Diversity within a cluster. In the controlled test, where every neuron is driven by one shared mode, members of a cluster are nonlinear neurons, but with the default potential each is an affine copy of the cluster's mean response to within a few per cent of variance (exactly so for linear neurons, nearly so with equal thresholds). Stronger fusion makes the copies closer, and stiffer potentials help only a little. With several modes, the larger differences inside a component come from chains that mix modes, which linear neurons show too. The reason is structural: a live edge certifies $D_{ij}^2 < 2b$, so fusing and being different are the same quantity pulling in opposite directions. Missing: a stage the energy does not see, or a term that rewards differences inside a cluster. Diversity
  • fails(T2) An allocation law $n(\lambda)$. In the basic model the attachments decide how many neurons a mode gets. A louder group of inputs is cut into more, smaller clusters, which is resolution, not allocation. Attachments made plastic under the same energy drain to the quietest inputs. An added principle, labelled as not derived from the energy, gives an exact water-filling law $q_a = (\lambda_a - \mu)_+$ for spectral mass, but neurons stay mixed across modes, so it is not a law for neuron counts. Missing: something that makes neurons specialise. Allocation
  • amended(T3) Clusters as eigenmodes. Exact for linear neurons: the population's eigenfunctions are $\Sigma_g$'s modes if and only if $H^\top H$ commutes with $\Sigma_g$. They coincide with the clusters, with eigenvalue $\nu n$ for a cluster of $n$ members of variance $\nu$, only when cluster prototypes are orthogonal, that is, when clusters draw on uncorrelated groups of inputs. With correlated groups the eigenfunctions are shared and contrast mixtures of clusters, and trained networks with random attachments match neither picture. Clusters versus eigenmodes
  • holds(T4) Weight-space readout, for linear neurons. Every live synapse states $D_{ij}^2 = 2(b - \alpha w_{ij})$, a linear equation on the input second moment. Once enough edges are alive, weights and attachments determine its contrast part $P\hat C P$ exactly. The common mode $C + \mathbf 1 a^\top + a\mathbf 1^\top$ is invisible in principle. The readout tolerates weight noise only just above percolation. For nonlinear neurons only a partial table of distances survives. And a covariance does not determine $p(\text{stimulus})$. Readout

So the model does explain the first half of the note: a local, Hebbian-looking rule that is exactly the gradient of a global energy, with an exact geometry in which, for linear neurons, the contrast part of the input statistics can be read back from the weights. It does not deliver the second half, an expansion code with a spectral allocation law, without ingredients that are not in it.

What changed from the first version

The first version took the note's rule literally: Hebb's covariance term, on linear neurons, with pruning added as a constant drift. It formed clusters, but they were degenerate. There was one cluster unless something pruned, members of a cluster were exact copies of each other, and the number of neurons per cluster was inherited from the transient. This version keeps the resistor network and changes three things: neurons have on-site potentials, so a response is a nonlinear function of the input; the objects compared are whole response functions; and the rule is derived from an energy, which supplies the two activity-power terms in (6) and builds pruning in. The old rule condenses what the first version found.
