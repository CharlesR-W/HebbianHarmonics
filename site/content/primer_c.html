Read the input statistics out of the weights

For linear neurons with stationary weights, each live synapse is one linear equation on the training inputs' contrast second moment \(P\hat C P\). Given the attachments and the rule, solve them.

derived and shown

\[ (h_i - h_j)^{\top} C\, (h_i - h_j) = 2\,(b - \alpha\, w_{ij}) \]

  • Exact once the equations are full rank and well conditioned.
  • More neurons than inputs makes it work: more live synapses, more equations.
  • Contrasts only, and a second moment is not the input distribution.

Nonlinear neurons: what carries over

Give each neuron a transfer function. The geometry and the readout of distances survive; the hoped-for expansion code does not appear.

shown
  • Carries over: the rule and its exact fixed point, now for whole response functions. Live synapses still state exact response distances; dead pairs give lower bounds.
  • Hoped for: many neurons per group, each a different function of the shared pattern, a rich code for downstream readers.
  • Measured: differences within a compact group are real but small, about 1–2% of the variance with spread thresholds (linear: 0.1–0.3%), and fusing makes such neurons more linear.

Plasticity parameters are clustering knobs

The constants in a plasticity rule play the role of the settings of a clustering algorithm.

shown
  • Covariance rule: the threshold \(\theta\) sets how many inputs each group spans.
  • Distance rule: \(b\) sets the resolution (how alike is "alike"); \(\alpha\) how tight the groups are and how much they remember their history.
  • So we can ask what trade-off a given homeostatic or pruning rule is making.

What we get, and what is open

  • Harmonic embeddings are the natural variables: each neuron is a point in the simplex of inputs, and Hebb's rule acts there.
  • Clusters are Perron parts of the thresholded input covariance, not its eigenvectors.
  • A local rule that descends a global energy, and weights from which the input statistics can be read back (exact for linear neurons, contrasts only).
  • Plasticity parameters as clustering knobs.

Open

  • Directed networks, through a directed Laplacian.
  • An allocation law: how many neurons each input pattern gets (none found in the basic model; Allocation).
  • An expansion code with real diversity inside a group (Diversity); noise.
