Does a neuron-wise nonlinearity such as ReLU have a useful general version? I tried the mildest one: keep the circuit linear and let plasticity see firing rates instead of voltages, on raw pixels with no kernel lift. That alone gives the rule access to higher moments: on digits it finds a different, heavier-tailed part, and a Gaussian control shows that this comes entirely from moments beyond the second. But the network is one cluster of identical neurons whose rates are a worse code than the pixels, so I have not run a stacked version; whether depth helps is still open.

Linear circuit, rectified output

Kirchhoff is untouched, so $u = Hg$ and the harmonic embeddings are the same functions of the weights as before. What changes is what plasticity correlates: the rate $r_i = c\,f(u_i - b_i)$ with $f = \mathrm{ReLU}$, and likewise $s_b$ for the inputs (rule (1)). Pixels are non-negative, so at $b_i = 0$ the ReLU does nothing (why); the threshold $b_i = \mathbb E[u_i] + \tau\,\mathrm{sd}(u_i)$ follows the neuron's own statistics (intrinsic-excitability homeostasis, outside $\rho(w)$; details), and larger $\tau$ makes firing sparser. For Gaussian inputs the rate covariance is then one convex, increasing function $k_\tau$ of the voltage correlation, scaled by the two voltage standard deviations ((2)). Normalised, $\tilde k_\tau = k_\tau/k_\tau(1)$ is the rate correlation as a function of the voltage correlation:

On real digits the shape survives: rate correlations sit on $\tilde k_\tau$ within a few hundredths. The scale does not. A learned part's rate variance is 1.6–4.1 times the Gaussian value for its voltage variance (larger for larger $\tau$), because, as the next section shows, the rule picks a skewed direction, whose upper tail is heavier than a Gaussian's.

Key point

For Gaussian inputs the rectified rule still sees only $\Sigma_g$. It replaces the inner product $\langle h_i, h_j\rangle_{\Sigma}$ by $\lVert h_i\rVert_\Sigma \lVert h_j\rVert_\Sigma\, k_\tau(\cos_\Sigma(h_i, h_j))$, a known convex increasing function of the same quantities. What changes is which fixed points the rule has, not what information it has.

The maths: the rule, $k_\tau$ in closed form, and why it is convex

The rule, with the threshold in the fast limit ($b_i$ computed from the exact moments of $u_i = h_i^\top g$ at the current weights):

$$\boxed{\begin{aligned}\frac{dw_{ij}}{dt} &= w_0 - \lambda w_{ij} + \gamma\eta\,\mathrm{Cov}(r_i, r_j)\\[2pt] \frac{dw_{ib}}{dt} &= w_0 - \lambda w_{ib} + \eta\,\mathrm{Cov}(r_i, s_b)\end{aligned}}$$

$\tau = 0$ rectifies deviations from the mean. If $(u_i, u_j)$ are jointly Gaussian with standard deviations $s_i, s_j$ and correlation $\rho$, then exactly

$$\mathrm{Cov}(r_i, r_j) = c^2\, s_i s_j\, k_\tau(\rho).$$

$k_\tau$ is one scalar function for every pair, because the threshold is measured in each neuron's own standard deviation. At $\tau = 0$ it is the degree-1 arc-cosine kernel minus the product of the means,

$$\begin{aligned}k_0(\rho) &= \frac{\sin\varphi + (\pi - \varphi)\cos\varphi - 1}{2\pi}, \quad \varphi = \arccos\rho\\ &= \frac{\rho}{4} + \frac{\rho^2}{4\pi} + \frac{\rho^4}{48\pi} + \dots\end{aligned}$$

its slope is the probability that both neurons fire, so it is increasing and convex.

With $X, Y$ standard normal with correlation $\rho$, $k_\tau(\rho) = \mathbb E[(X-\tau)_+(Y-\tau)_+] - m_\tau^2$, where $m_\tau = \varphi(\tau) - \tau\Phi(-\tau)$. By Price's theorem $k_\tau'(\rho) = \Phi_2(-\tau,-\tau;\rho) = P(X > \tau, Y > \tau)$ and $k_\tau''(\rho) = \varphi_2(\tau,\tau;\rho) > 0$; $k_\tau(0) = 0$, $k_\tau(1) = \mathrm{Var}((X-\tau)_+)$, $k_\tau(-1) = -m_\tau^2$. Integrating twice from $\rho = 0$ (substituting $s = \sin t$ to remove the endpoint singularity):

$$k_\tau(\rho) = \rho\,\Phi(-\tau)^2 + \frac{1}{2\pi}\int_0^{\arcsin\rho} (\rho - \sin t)\, e^{-\tau^2/(1+\sin t)}\,dt .$$

$\tilde k_\tau$ lies below the diagonal on $(0,1)$, further below for larger $\tau$: $\tilde k(0.5) = 0.43, 0.38, 0.31$ at $\tau = 0, 0.5, 1$, and negative correlations are squashed towards $\tilde k(-1) = -0.47, -0.23, -0.10$. For Gaussian $g$ the lateral drift is therefore $\gamma\eta c^2\,\lVert h_i\rVert_\Sigma\lVert h_j\rVert_\Sigma\,k_\tau\big(h_i^\top\Sigma_g h_j/\lVert h_i\rVert_\Sigma\lVert h_j\rVert_\Sigma\big) + w_0 - \lambda w_{ij}$, and the input drift is the same expression with $h_j = e_b$. Checked against Monte Carlo ($10^6$ samples) and the sampled rate covariances in hebb/nonlin/test_nonlin.py.

Live, on a synthetic ring: not a remap of $\theta$, but more and narrower clusters at the same pairwise threshold

Is the Gaussian rectified rule just the linear rule with $\theta$ moved? Take unit-variance inputs and a correlation threshold $\rho^\ast$. The linear rule at $\theta = \rho^\ast$ and the rectified rule at $\theta = \tilde k_0(\rho^\ast)$ (gain $c^2 = 1/k_0(1)$) bind exactly the same pairs of inputs. If rectification were a remap, the two networks would end in the same place. Run them:

At the same pairwise threshold the rectified rule populates more and narrower clusters, and keeps some alive where the linear population has gone extinct. The reason is convexity together with the two norms. Interior neurons have $s_i < 1$, because averaging lowers variance. Partially correlated pairs, which are the bonds between prospective clusters, are discounted by $\tilde k(\rho)/\tilde k(\rho^\ast) < \rho/\rho^\ast$, while perfectly correlated pairs within a cluster need only $s^2 > \tilde k(\rho^\ast)$ instead of $s^2 > \rho^\ast$. So the rule prunes between-cluster bonds harder and keeps lower-variance clusters alive: coincidence detection, which is what $k_\tau' = P(\text{both fire})$ says.

Real digits: a different part

14×14 MNIST pixels ($B = 196$, scaled to mean pixel variance 1), $N = 980$, dense random initial weights, $\gamma = 1$, 3,000 minibatch steps (batch 256), weights averaged over the last 20%. To compare rules fairly, each sits at the same quantile $q$ of the off-diagonal input covariance it sees: $\Sigma_g$ for the linear rule, $c^2\,\mathrm{Cov}(s_b, s_c)$ for the rectified one.

At $q = 0.980$ the linear rule's dominant part is a short slanted "/" stroke (at lower $q$, two slanted strokes). The rectified rule's is two vertical bars, the left and right sides of a "0", at every $q$ and $\tau$. The difference grows with $q$ and with $\tau$, and it replicates with a second seed, with $\gamma = 0$, and at 28×28 ($N = 3920$: cosine to the linear part 0.05–0.10). It also shows in how the networks get there: both pass through the same transient "0-ring" (the global Perron part), but the linear rule stays on it until about step 500, while the rectified rule leaves it by step 40.

The control: Gaussian pixels with the same covariance

To see whether the new part comes from higher moments, I replaced the digits by Gaussian samples with the same mean and covariance and kept everything else. At its own quantile the surrogate learns the linear part. With the rectified network's exact $\theta$ and $c$ it is worse off: at the lowest $q$ it learns a non-skewed part, then it loses 931 of 980 neurons at $q = 0.967$, and dies entirely above. Everything the rectified rule does differently on MNIST comes from moments beyond the second. The direction it finds is the heavy-tailed one, which is the classical result that nonlinear Hebbian rules do projection pursuit, here appearing inside the resistor network.

Linear probes: every trained network is a redundant code, and the cluster count, not the nonlinearity, decides how much it keeps

Every trained network, under either rule, is a highly redundant code, and the cluster count, not the nonlinearity, decides how much it keeps: a one-cluster linear network probes at about 0.22, like the rectified ones, and the linear rule does better only when it fragments on its way to extinction. All are below the pixels and the untrained network, and far below random ReLU features.

Reading $\Sigma_g$ back by inverting $k_\tau$: within a few per cent on Gaussian inputs, biased on digits by exactly the measured excess

Inverting $k_\tau$ recovers $\Sigma_g$ on synthetic Gaussian data (contrast cosine 0.9995 when the clusters span the blocks), and nets trained on Gaussian pixels read back their part's energy within a few per cent, with lateral plasticity ($\gamma = 1$; at $\gamma = 0$ they give 0.74–0.91). On digits it inflates the part's energy by exactly the measured excess, and inverting the exact expected rate covariance gives the same bias, so it comes from the Gaussian closure, not from non-equilibrium. What is identifiable changes too: the rectified equations also involve the input variances $C_{bb}$, so they can see directions the linear readout cannot (one cloned cluster $h = (\tfrac12, \tfrac12)$, $C = I$, two input and one lateral equation: local Jacobian rank 3 against 2). Identifiability has to be judged by that local rank, and an unknown $\theta$ or $\lambda/\eta$ is no longer a simple gauge, though a fitted $\theta$ comes back near 0 whatever the truth.

Verdict, and what it means for stacking

What we found

  • holdsRectification gives the rule higher moments without a kernel lift. On digits it finds a different, skewed, heavy-tailed part, and the Gaussian control removes the difference completely.
  • amendedFor Gaussian inputs it adds no information. The rule is still a function of $\Sigma_g$, through a convex dual activation; that changes the fixed points (more and narrower clusters at the same pairwise threshold), not what can be learned.
  • failsA better code. The rectified network is one cluster of exact clones computing a single function. Its rates are a worse code than the raw pixels or the untrained network's; a one-cluster linear network probes the same (about 0.22).
  • openThe allocation law. The rectified rule never populated two or more major clusters on MNIST, so it cannot be tested here.
  • amendedWeight-space readout. It survives under the Gaussian assumption (with $\gamma = 1$); on real data it is biased by exactly the measured higher-order gap. What it identifies is set by the local Jacobian rank, and can exceed the linear readout.

Why I have not stacked it. On raw MNIST a second layer fed by these rates would see 980 copies of one function of the input: one effective input. That is a fact about this first layer on digits, not about depth. On the synthetic ring, rectification keeps 7–9 parts populated where the linear rule keeps 1 (live figure, $\rho^\ast = 0.6$, three seeds), so whether a hierarchy helps is still open; it needs a first layer that keeps several parts populated on real data.

Speculation, not tested: what might make depth worth trying

Speculation, not tested

What might make depth worth trying. Each item attacks one of the two failures above, collapse to one cluster or clones within it. Private noise per synapse breaks the permutation symmetry that keeps clones identical, but in the linear model it gave only jitter that averages out, not distinct functions (Homeostasis). Sparse random wiring without lateral plasticity gave a few distinct functions per mode in the linear model. Per-neuron thresholds (different $\tau_i$) would make members of one part fire on different subsets of stimuli. And something must stop the dense population binding into one blob on the first, loudest part: switching lateral plasticity off ($\gamma = 0$) did not, so a heavy-tailed initial input weighting or a smaller leak would be the next things to try.
