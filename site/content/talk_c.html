Read the inputs out of the weights

Given the learned weights, how the neurons are wired to the inputs, and the learning rule, you can solve for the statistics of the inputs the network was trained on.

\[ (h_i - h_j)^{\top} C\, (h_i - h_j) = 2\,(b - \alpha\, w_{ij}) \]

Distance rule: each surviving synapse gives one linear equation on the inputs' second moment \(C\), saying how differently its two neurons responded.

  • Linear network at equilibrium: with enough surviving synapses, we recover exactly how the training inputs varied relative to one another (not the part shared by all inputs).
  • It needs the rule's exact form and constants.

Plasticity parameters are clustering knobs

The constants in a plasticity rule play the role of the settings of a clustering algorithm.

  • Fusion scale b: resolution, a length rather than a number of groups.
  • α: how tight the groups are, and how much they remember their history; not when fusion starts.
  • So we can ask what trade-off a given homeostatic or pruning rule is making.

Open: a neuron allocation rule?

Perhaps plasticity parameters set how many neurons each input pattern gets, as a function of its energy.

\[ n_a = n(\lambda_a) \]

  • Represent many different input patterns, or devote more neurons to just a few?
  • So far: with fixed wiring, the wiring sets the counts (a louder block of inputs is only cut finer); when the wiring learns, neurons drain to the quietest inputs.
  • An added objective gives water-filling for variance, not for neuron counts.

What we get

  • A minimal-assumption model of Hebbian learning that says what it computes: clustering of harmonic embeddings.
  • Harmonic embeddings are the natural variables for interpretability.
  • The input statistics can be inferred from the weights, the input wiring and the plasticity rule (exact with enough surviving synapses, except the part shared by all inputs).
  • Plasticity parameters are the parameters of a clustering algorithm, possibly a neuron-allocation rule (open).
