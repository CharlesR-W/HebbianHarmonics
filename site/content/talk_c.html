Read the inputs out of the weights

Given the learned weights and the learning rule, you can solve for the statistics of the inputs the network was trained on.

derived

\[ H\,C\,H^{\top} = R(w) \;\Rightarrow\; C = H^{+} R\, H^{+\top} \]

Written for the original covariance rule. In the distance rule, each surviving synapse gives one equation: how differently its two neurons responded.

  • Linear network at equilibrium: with enough surviving synapses, we recover exactly how the training inputs varied relative to one another (not their shared fluctuation).
  • Nonlinear network: only part of the distances between neurons is recovered.

Plasticity parameters are clustering knobs

The constants in a plasticity rule play the role of the settings of a clustering algorithm.

shown
  • Fusion scale b: resolution, i.e. how many groups.
  • α: how tight the groups are, and how much they remember their history; not when fusion starts.
  • So we can ask what trade-off a given homeostatic or pruning rule is making.

Open: a neuron allocation rule?

Perhaps plasticity parameters set how many neurons each input pattern gets, as a function of its energy.

conjecture

\[ n_a = n(\lambda_a) \]

  • Represent many different input patterns, or devote more neurons to just a few?
  • So far: in the base model, counts are set by wiring and the fusion scale; plastic wiring drifts to quiet inputs; no tested ingredient gives n ∝ energy.

What we get

  • A minimal-assumption model of Hebbian learning that says what it computes: clustering of harmonic embeddings.
  • Harmonic embeddings are the natural variables for interpretability.
  • The input statistics can be inferred from the weights plus the plasticity rule (exact in the linear case with enough surviving synapses, up to the inputs' shared fluctuation).
  • Plasticity parameters are the parameters of a clustering algorithm, possibly a neuron-allocation rule (open).
