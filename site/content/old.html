Two further observations about Hebb's covariance rule with a pruning threshold, the model of Perron clusters. Inside each group, the neurons become indistinguishable copies of one another, to within numerical precision. And at fixed inputs and settings, how many neurons each group gets depends on the random starting weights.

As a reminder, every synapse, including those from the inputs, follows

$$\frac{dw_{ij}}{dt} = \eta\big(h_i^\top \Sigma_g h_j - \theta\big) - \lambda w_{ij}, \qquad w_{ij} \ge w_{\min},$$

where $h_i$ is neuron $i$'s mixture of the inputs; for a synapse from input $b$, that end's mixture is $e_b$ (the input itself). A synapse grows while its two ends covary by more than $\theta + \lambda w_{ij}/\eta$ and shrinks otherwise; the floor $w_{\min}$ stops it from shrinking further. All inputs here are synthetic.

Members of a group become indistinguishable

With every neuron wired to every other, this held in every run we made: over the … precomputed runs (…; … inputs, … neurons), the largest $L_1$ distance from any neuron's mixture to its group's mean mixture was …. The rule treats all neurons alike, which only guarantees that neurons which start identical stay identical; that neurons which start apart become indistinguishable is an observation, not a theorem.

A neuron here computes a linear function of the input, $u_i = h_i^\top g$, so two neurons with the same mixture compute the same function. Even slightly different members would only be different mixtures of the same few inputs.

The starting weights affect how many neurons each group gets

Nothing at the fixed point pins these sizes down. The condition for where a group sits does not contain its number of members (see Perron clusters), so with a zero floor, any split of the neurons among compatible, disconnected groups is a fixed point. A finite floor couples the groups; for start 1 of each panel, lowering $\omega$ to … moved the split by at most … neuron per group.

So the split is decided on the way. With a zero floor and no lateral synapses, a neuron's input weights run, in rescaled time, a continuous non-negative power iteration on $\Sigma_g - \theta\mathbf 1\mathbf 1^\top$ from where they started, and where they end depends on that start.
