What Hebb does: it groups

Neurons that listen alike fuse into groups; neurons that listen differently disconnect.

shown

\[ \text{link } i\!-\!j \text{ survives} \iff \lVert h_i - h_j \rVert^2 < 2b \]

  • The fusion scale b sets how alike is "alike".
  • Bigger b: fewer, larger groups. Small b: everyone alone.
  • In the real model the middle is messy: some small groups, many loners, then one giant group. Not a few tidy clusters.

Not just eigenvectors: a hierarchy

Turning the fusion scale down splits groups into subgroups, so one rule gives a coarse-to-fine description.

conjecture
  • Shown: as b shrinks, groups split into children, nested cleanly except near the point where one giant group forms.
  • Hoped: each group stands for the main pattern of the block of inputs it listens to, not of all inputs at once.
  • Found so far: that reading holds when the blocks are uncorrelated and built in; with correlated blocks the group-level patterns follow the whole input's modes instead.

An expansion code?

The hope: many neurons per pattern, each a different function of it, so downstream readers get a rich set of features.

conjecture
  • Shown: every neuron's response is a function of the shared pattern z.
  • Measured: after rescaling, linear or identical neurons give the same curve. Varied thresholds add differences worth only about 2% of response variance, and fusion shrinks that.
  • So the basic model does not deliver this yet.
